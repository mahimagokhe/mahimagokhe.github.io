The product problem

Weather data is useful only when people can understand change quickly. This dashboard brings current conditions, hourly forecasts, trends, alerts, and location search into one responsive surface without overwhelming the user.

A responsive weather dashboard built with Angular for a modular UI, D3.js for interactive visualizations, and a lightweight Node.js backend for API caching. The app provides real-time forecasts, historic trend charts, and alerting for severe weather — designed to help users quickly understand current conditions and short-term trends.

Key Features

  • Real-time weather and hourly forecasts with a performant REST proxy (Node.js).
  • Interactive D3 visualizations for temperature, precipitation, and wind trends.
  • Geolocation & search with cached results for fast UX and reduced API calls.
  • Responsive Angular components with accessible UI and offline-friendly caching.

My Role & Implementation Notes

Implemented core Angular components, created D3 chart integrations, optimized data handling with RxJS and change-detection strategies, and built a Node.js caching layer to minimize external API requests.

Technical walkthrough

Data visualization layer

D3 integrations translate forecast data into interactive temperature, precipitation, and wind views, with responsive presentation for dense hourly information.

API and state flow

Angular components use RxJS for asynchronous weather data, while a Node.js proxy caches responses to reduce repeated external requests and improve perceived speed.

Responsive product behavior

Search, current conditions, chart, hourly cards, alerts, loading states, and offline-friendly caching are designed as connected states rather than isolated screens.

Why it reflects experienced frontend work

The project combines external data uncertainty with a high-frequency information interface. It demonstrates API boundaries, caching, reactive state, visualization choices, accessibility, and responsive prioritization across devices.
