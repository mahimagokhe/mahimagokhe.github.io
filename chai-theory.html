Chai Theory

A premium scroll experience for an Indian café, designed around tactile food storytelling, cinematic pacing, and camera-friendly interaction beats.

HTML · CSS · JavaScriptGSAP · ScrollTriggerLenis smooth scrollMotion design
The experience goal

Build a café site that feels more like a short film than a menu page. Each scroll should create a deliberate reveal, while the experience stays resilient when media assets are missing or autoplay is restricted.

What I built

Chai Theory is a single-page prototype with a full-bleed hero, scroll-controlled product moments, and a visual rhythm shaped for both real browsing and short-form video capture.

Scroll choreography

GSAP and ScrollTrigger coordinate pinned sections, scrubbed transitions, parallax movement, and timed visual reveals.

Food as the interface

Exploded thali and samosa scenes make ingredients and craft feel tangible rather than presenting another static card grid.

Smooth navigation

Lenis creates a controlled scroll rhythm that lets large media moments land cleanly without making the page feel abrupt.

Resilient media

Missing videos and images fall back gracefully so the layout remains usable during development, review, and deployment.

Frontend engineering decisions

  • Separated the visual system, interaction logic, and page structure across styles.css, main.js, and index.html.
  • Designed the motion system around scroll position rather than isolated decorative animations, keeping narrative and interaction connected.
  • Added a ?reel=1 playback mode for consistent automated scroll timing and a repeatable 1920×1080 capture workflow.
  • Handled autoplay and missing-asset constraints so the core composition still communicates when the ideal media environment is unavailable.

Why it represents senior frontend work

The project demonstrates component-minded page composition, animation sequencing, media performance awareness, graceful degradation, and an understanding of how interaction design changes the perceived value of a product. It turns a visual brief into a controlled, testable frontend experience.
