📊 SpendSense — Expense Tracker

Technologies: HTML, CSS, JavaScript (vanilla), Canvas, Web Speech API, localStorage

This is a lightweight, client-side expense tracker focused on quick entry and visibility. It supports typed and voice/chat input, animated category charts, light/dark theming, per-month budgets stored in localStorage, and a simple Excel export (SpreadsheetML) for backups.

Key Features

  • Voice-driven expense entry using the Web Speech API (click the mic or say the wake word).
  • Chat / natural-language parsing to extract amount, date, and category from free text.
  • Animated canvas-based category chart with hover tooltips and an HTML legend.
  • Light and dark theme toggle persisted to localStorage.
  • Per-month storage and export to a SpreadsheetML .xls file.

Project Features

  • Expense Tracker (UI): A lightweight expense manager implemented in HTML/CSS/JavaScript. See expense-tracker for the full implementation. Core UI functions include addExpense(), deleteExpense(), editExpense(), render() and save() which manage the entry lifecycle and persistence.
  • Microphone / Voice Input: Voice-driven expense entry uses the Web Speech API (SpeechRecognition). The microphone control is voiceBtn in expense-tracker. Key code elements: recognition (continuous listening), startContinuousRecognition() / stopContinuousRecognition() to control listening, and startCommandRecognition() to capture one-shot commands after a wake word. Recognized text is passed to parseMessage() for extraction.
  • Chatbot / Natural Language Parsing: A small rule-based parser converts natural language into expenses. Implemented in parseMessage() and helper functions in expense-tracker. It extracts amounts (regex), dates (parseDateToken()), and categories (findCategoryFromText() using the categoryKeywords mapping), then calls addExpenseFromChat() to persist the parsed expense.
  • Dark / Light Theme: Theme toggling is implemented using a light-mode CSS class on the document root and localStorage to persist the choice. Relevant functions: setTheme(), toggleTheme(), and initTheme() (see expense-tracker). Global site-level variables and dark-mode styles also appear in My Portfolio.
  • Charts & Visuals: Category percentage chart is drawn on a <canvas> by drawChart() with animated slices and interactive hover tooltips. The HTML legend is built by renderLegend() (see expense-tracker).
  • Persistence & Export: Expenses and per-month budgets are stored in localStorage under keys like YEAR-MONTH and YEAR-MONTH-budget. Export to Excel is provided by downloadAllMonths() which generates a SpreadsheetML .xls file.
  • How to use key features:
    • Theme: Click the floating Theme button (top-right) to toggle light/dark; the selection is saved to localStorage.
    • Voice: Click the mic (voiceBtn) and allow microphone access; say a phrase like "I spent 50 on tea today" or use the wake word ("Hey Tracker") then speak a command.
    • Chat: Type in the chat input and click Send — the message is parsed by parseMessage() and added if it contains an amount.
